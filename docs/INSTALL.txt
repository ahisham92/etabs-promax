CSI ProMax: first install

Nothing here is an .exe and nothing needs administrator rights for ETABS 23.

The quick way: one line
Open Windows PowerShell (Start menu, type "PowerShell"), paste this line and press Enter:

   irm https://raw.githubusercontent.com/ahisham92/etabs-promax/main/install.ps1 | iex

It downloads the newest version into Documents\CSI ProMax, looks for the .NET 8 Desktop Runtime (and gets it from
Microsoft into your user folder when the PC has none), and adds "CSI ProMax" to the Tools menu of each ETABS, SAFE and
SAP2000 that is closed and has no other plug-in. It keeps a copy of each settings file it changes, and never starts,
closes or changes a CSI program or a model. Then open the program and a model, and choose Tools > CSI ProMax.
For a program it could not add itself to, it prints the plug-in name and file to add by hand (the steps below).
Run the same line again at any time: it only replaces what changed.
Without the AI chat
The same line, for CSI ProMax without the AI chat: the Modeler (modelling by hand in the 3D view, Define forms and
Excel tables), the 3D view of an open model, review packs and the Viewer, with no Claude Code used or installed:

   irm https://raw.githubusercontent.com/ahisham92/etabs-promax/main/install-no-ai.ps1 | iex

Everything else is the same: the same files, Tools > CSI ProMax in each program, and updates that go in without closing
the program. Running the plain line again later keeps the choice. To turn the chat on or off afterwards, use the
CSI ProMax menu in the window (Turn the AI chat on / off): CSI ProMax starts again with it, and the program and the
model stay open. With the chat on, the 3D view in the browser has a Chat tab too: the same conversation as the window.
Modelling and viewing work with or without ETABS, SAFE or SAP2000 on the PC. Without one, start the "CSI ProMax
Modeler" shortcut (the install makes it), or double-click "Open the Modeler.cmd" in Documents\CSI ProMax.

If that address cannot be reached, this line gets the same script from the releases page:

   irm https://github.com/ahisham92/etabs-promax/releases/latest/download/install.ps1 | iex

When it is done it tries, for each program, what Tools > CSI ProMax does, and says yes or no for each.
It works with ETABS 18 and later, SAFE 20 and later and SAP2000 20 and later.

If Tools > CSI ProMax does not open ("Cannot create plugin!", or "Not Found" in the plug-in list)
Paste this line into Windows PowerShell. It only looks: it changes nothing. It prints what it found for each program
and copies that text, to paste into a message to the person who gave you CSI ProMax:

   irm https://raw.githubusercontent.com/ahisham92/etabs-promax/main/check.ps1 | iex

The rest of this file is the same install by hand.

ETABS 23
1. Copy the "dist" folder from this zip to your Documents folder and rename it "CSI ProMax".
2. In ETABS: Tools > Add/Show Plugins. Browse to Documents\CSI ProMax\CsiProMaxPlugin.dll and add it with the
   menu text "CSI ProMax".
3. Open a model, then Tools > CSI ProMax. The window opens beside ETABS.

Older ETABS (18 to 22). Not yet confirmed on these versions: please report what happens.
1. Install Microsoft's ".NET Desktop Runtime 8" (x64) once. It is free:
   https://dotnet.microsoft.com/download/dotnet/8.0  (choose ".NET Desktop Runtime", Windows x64).
   ETABS 23 brings .NET 8 with it; older ETABS does not, and CSI ProMax's window needs it.
2. Then the three steps above.
If the window does not open, CSI ProMax shows a message that says what is missing.

SAFE (20 and later)
1. Copy the folder as for ETABS (one "CSI ProMax" folder serves ETABS and SAFE).
2. In SAFE: Tools > Add/Show Plugins. Browse to Documents\CSI ProMax\CsiProMaxSafePlugin.dll, plug-in name
   CsiProMaxSafePlugin, menu text "CSI ProMax".
3. Open a model, then Tools > CSI ProMax. The same window opens, working in SAFE: slabs, mats, punching shear,
   deflection, strip forces, soil pressure and slab design.
If SAFE runs on .NET Framework (older versions), install the .NET Desktop Runtime 8 first, as for older ETABS.
Not yet confirmed in SAFE: please report what happens.

SAP2000
1. Copy the folder as for ETABS (the same "CSI ProMax" folder serves every program).
2. In SAP2000: Tools > Add/Show Plug-Ins. Plug-in name "CsiProMaxSapPlugin", path
   Documents\CSI ProMax\CsiProMaxSapPlugin.dll, menu text "CSI ProMax". Add it.
3. Open a model, then Tools > CSI ProMax. The same window opens, working in SAP2000: joints, frames and areas in 3D,
   loads in any direction, displacements, member forces, reactions, modes and steel and concrete design.
SAP2000 26 and later run on .NET 8. An older SAP2000 needs the .NET Desktop Runtime 8 first, as for older ETABS, and
may not load the plug-in yet: then, with SAP2000 open, run  dotnet CsiProMax.dll --program sap2000  in that folder.
Not yet confirmed in SAP2000: please report what happens.

The chat runs on Claude Code on your own Claude plan. The window offers to install it or sign in when needed.
If the window says Claude Code isn't installed although it is: the card says where it looked, and names any file it
found but could not start. "Choose the file" lets you point at claude.exe yourself, and "Copy details" copies what it
saw, to send back. To check by hand, run this in PowerShell:  where.exe claude; claude --version; whoami
("not recognized" means Claude Code is not installed for this Windows user; the Claude desktop app is another program.)
A PC other than the owner's needs a licence key: the Licence window shows this PC's code (SPM-....); send it to the
owner and paste the key you get back.
Later versions download by themselves (CSI ProMax > Check for updates). The CSI program must be open and licensed on
this PC: CSI ProMax never starts, unlocks or stands in for it.

The Modeler (no ETABS and no CSI licence needed)
It builds a model and writes an .e2k file that ETABS opens later, one floor or a mat as an .f2k file for SAFE
(File > Import > SAFE .F2K file), or the whole model as an .s2k file for SAP2000 (File > Import > SAP2000 .s2k Text File). It does not analyse or design: that needs ETABS.
- On a PC with ETABS: the first time the window opens it puts "CSI ProMax Modeler" and "CSI ProMax Viewer"
  shortcuts on the desktop and in the Start menu (CSI ProMax). Delete one and it stays deleted; View > Make the
  Modeler and Viewer shortcuts again brings them back.
- On a PC with no ETABS: install ".NET Desktop Runtime 8" (x64) as above, copy the "dist" folder to Documents and
  rename it "CSI ProMax", then double-click "Open the Modeler.cmd" inside it.
